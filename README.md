# Ethan Love Music

## Installation

### Clone repository

```shell
git clone git@github.com:robertlove/ethanlovemusic.git
cd ethanlovemusic
```

### Install dependencies

```shell
bundle install
```

## Usage

### Serve site

```shell
bundle exec jekyll serve
```
